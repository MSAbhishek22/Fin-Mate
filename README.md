## 📖 The Story

This one needs honesty before decoration: **`Fin-Mate` is an empty repository.** It was created on **24 August 2025** — and as of this README, it contains no files, no code and no commits of substance. Nothing here has been built yet, and this page will not pretend otherwise.

What exists is an intention, captured in a name. *Fin* — finance. *Mate* — a companion, not a dashboard. By August 2025, the pattern of this portfolio was already clear: build companions for the parts of student life that feel lonely — a *Sathi* for study material, a tracker for goals, a graph for concepts. Money is the obvious next lonely subject: the first stipend, the first internship salary, the hostel-month budget that evaporates by the 20th.

So the repo was created the way a writer reserves a title. The book isn't written. This README is the cover page that says so — loudly, instead of leaving a blank repo to look abandoned.

---

## 🎯 The Problem

*The problem this project was named to eventually attack:*

- 💸 Students handle real money for the first time — stipends, pocket money, freelance payouts — with zero tooling that speaks their language.
- 🏦 Mainstream finance apps are built for salaries, EMIs and portfolios, not for a ₹500 recharge decision in a hostel room.
- 📊 Expense tracking feels like accounting homework, so it gets abandoned within a week.
- 🤐 Money questions feel embarrassing to ask friends or family — a private, judgement-free *mate* could be asked anything.

*⚠️ Framing note: this is the intended problem space, not a shipped solution.*
